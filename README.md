# Evolusi PL - Laravel Project

Project Laravel sederhana untuk tugas Evolusi Perangkat Lunak.

## Fitur

- Halaman Beranda (`/`)
- Halaman Tentang (`/about`)
- Halaman Profile (`/profile`)

## Struktur Branch

- `main` — branch stabil/production
- `dev` — branch development
- `feature/*` — branch untuk pengembangan fitur baru
